# JP Media Viewer

> 本项目完全由 AI 完成，包括代码实现、文档编写、发布流程配置和版本发布辅助。

一个简洁的 Android 随机媒体浏览器。添加本地文件夹后自动扫描图片和视频，支持媒体缓存、随机浏览、手势切换、收藏列表、文件详情和关于/反馈入口。

## 功能

- **文件夹选择**：通过系统文件选择器（SAF）添加一个或多个图片/视频文件夹。
- **自动扫描**：添加文件夹或修改 `.nomedia` 设置后自动扫描，已缓存的结果可直接加载，不必重复扫描。
- **媒体缓存**：扫描结果会在本机缓存；文件夹和 `.nomedia` 设置未变化时，下次打开可直接浏览。
- **扫描进度**：首页显示已检查文件数、已找到媒体数、当前扫描文件和完成提示。
- **暂停/继续扫描**：扫描过程中可随时暂停，进度自动保存到本机；点击“继续补扫”从断点恢复，已找到媒体可先行浏览。
- **重新扫描**：首页提供“继续补扫”或“重新扫描”按钮（有部分缓存时显示前者），文件新增、删除或缓存过期时可手动刷新媒体列表。
- **扫描统计详情**：扫描完成后显示每个文件夹的检查文件数、媒体数、跳过 `.nomedia` 目录数、失败目录和耗时。
- **缓存管理**：提供清除媒体缓存、查看缓存状态、清除收藏等功能。
- **媒体加载失败提示**：浏览时如果图片或视频文件已删除、授权失效或无法打开，会提示重新扫描刷新媒体列表。
- **空结果提示**：没有找到媒体时提示可能原因，包括目录无媒体、`.nomedia` 过滤、文件夹授权失效等。
- **.nomedia 支持**：可选择是否遵守 `.nomedia` 文件，灵活控制扫描范围。
- **随机浏览**：扫描完成后随机排序媒体文件，每次浏览都有不同顺序。
- **手势浏览**：上滑下一张，下滑上一张，单击显示或隐藏控制栏。
- **收藏功能**：点击浏览页底部心形按钮即可收藏/取消收藏，收藏状态会持久保存，并显示操作提示。
- **收藏列表**：首页提供“查看收藏”入口，可只浏览已收藏媒体；收藏为空或收藏文件失效时会显示提示。
- **子文件夹模式**：浏览页可切换为只看当前媒体所在子文件夹，再次点击即可返回全部媒体。
- **子文件夹排序**：子文件夹浏览模式下可按文件名、文件大小或随机排序，支持正序/逆序切换。
- **文件信息**：底部显示文件大小和所属文件夹；点击文件夹信息可复制文件夹名称，长按媒体可打开详情弹窗查看文件名、日期、大小、文件夹和收藏状态。
- **文件夹详情**：首页点击文件夹列表项可查看完整 URI 并一键复制到剪贴板。
- **图片缩放和平移**：图片支持双指缩放，放大后可拖动查看细节。
- **视频播放控制**：视频提供播放/暂停、可拖动进度条、当前时间与总时长显示、静音开关，静音选择会持久保存；默认自动循环播放。
- **快速跳转**：浏览时点击顶部的序号（如「12 / 340」）可输入序号跳转到指定的第 N 项。
- **分享与打开**：长按媒体打开详情弹窗，可将当前文件分享到其他应用，或用其他应用打开。
- **Material You**：Android 12+ 支持莫奈动态取色；低版本 Android 使用普通 Material3 主题以保持兼容。
- **关于与反馈**：首页右上角“关于”入口展示版本号、构建类型、开发者、许可证、隐私说明、第三方组件，并可打开项目地址和 GitHub Issues 反馈页。

## 可能会有的功能

## 使用方式

1. 打开应用，点击“添加文件夹”。
2. 选择包含图片或视频的目录，并授予读取权限。
3. 等待首页自动扫描完成。扫描结果会缓存在本机，下次打开同一组文件夹时可直接浏览。
4. 扫描过程中可随时暂停，进度自动保存；之后点击"继续补扫"从断点恢复。如果文件夹内容发生变化，点击“重新扫描”刷新媒体列表。
5. 点击“开始浏览”进入随机浏览，或点击“查看收藏”只浏览已收藏媒体。
6. 浏览时可使用以下操作：

| 操作 | 效果 |
|---|---|
| 单击 | 显示或隐藏顶部/底部控制栏 |
| 上滑 | 下一张 |
| 下滑 | 上一张 |
| 双击图片 | 放大或还原图片 |
| 心形按钮 | 收藏或取消收藏当前媒体 |
| 顶部筛选按钮 | 只看当前媒体所在子文件夹 / 返回全部媒体 |
| 点击顶部序号 | 输入序号跳转到第 N 张 |
| 视频控制栏 | 播放 / 暂停、拖动进度条、静音切换 |
| 长按 | 查看文件详情，并可分享或用其他应用打开 |

首页右上角“关于”按钮可查看版本号、项目地址、许可证、隐私说明和问题反馈入口。

## 收藏

- 点击浏览页底部的❤️按钮即可收藏或取消收藏当前媒体，操作后会有提示。
- 首页“查看收藏”按钮会显示当前保存的收藏数量。
- 收藏浏览模式只显示当前已扫描目录中仍然可访问的收藏媒体。
- 如果收藏文件已删除、所在文件夹未添加，或文件夹授权失效，应用会给出提示。

## 构建

在 Android Studio 中打开 `android/` 目录，或通过命令行构建：

```bash
cd android
./gradlew assembleDebug
```

Windows：

```powershell
cd android
.\gradlew.bat assembleDebug
```

Debug：`android/app/build/outputs/apk/debug/jp-media-viewer-{versionName}-debug.apk`；Release：`android/app/build/outputs/apk/release/jp-media-viewer-{versionName}-release.apk`

## 技术栈

| 层 | 技术 |
|---|---|
| UI | Jetpack Compose + Material3 |
| 图片 | Coil 2.5 |
| 视频 | Media3 / ExoPlayer 1.2 |
| 文件访问 | Storage Access Framework |
| 设置存储 | SharedPreferences |
| 构建 | Gradle + Kotlin DSL |
