功能特性

📂

文件夹选择

通过 SAF 添加图片/视频文件夹，无需存储权限。

🔀

随机浏览

每次浏览随机排序，上滑下一张，下滑上一张。

❤️

收藏管理

收藏你喜欢的媒体，支持收藏列表和仅浏览收藏模式。

⚡

媒体缓存

扫描结果自动缓存，下次打开无需重复扫描。

🎨

Material You

Android 12+ 支持 Monet 动态取色，低版本保持兼容。

🔄

暂停/续扫

扫描过程中可暂停，进度保存，随时从断点恢复。

🔍

缩放平移

图片支持双指缩放，放大后可拖动查看细节。

📁

子文件夹模式

切换到当前媒体所在子文件夹浏览，支持排序。

快速开始

1

下载 APK

从 GitHub Releases 页面下载最新版本的 APK 文件。

2

安装并打开

安装 APK，打开应用。无需授予任何权限。

3

选择文件夹

通过 Android SAF 选择包含图片或视频的文件夹。

4

开始浏览

媒体自动扫描并开始随机浏览，上滑/下滑切换。

UI Jetpack Compose + Material3
图片 Coil 2.5
视频 Media3 / ExoPlayer 1.2
文件访问 SAF
语言 Kotlin
构建 Gradle + Kotlin DSL
