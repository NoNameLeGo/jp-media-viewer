JP Media Viewer

简洁的 Android 随机媒体浏览器。无需权限，通过 SAF 添加文件夹，自动扫描图片和视频，支持随机浏览、手势切换、收藏列表。

下载 APK GitHub

功能特性

📂

文件夹选择

通过 SAF 添加图片/视频文件夹，无需存储权限。

🔀

随机浏览

每次浏览随机排序，上滑下一张，下滑上一张。

❤️

收藏管理

收藏你喜欢的媒体，支持收藏列表和仅浏览收藏模式。

⚡

媒体缓存

扫描结果自动缓存，下次打开无需重复扫描。

🎨

Material You

Android 12+ 支持 Monet 动态取色，低版本保持兼容。

🔄

暂停/续扫

扫描过程中可暂停，进度保存，随时从断点恢复。

🔍

缩放平移

图片支持双指缩放，放大后可拖动查看细节。

📁

子文件夹模式

切换到当前媒体所在子文件夹浏览，支持排序。

技术栈

UIJetpack Compose + Material3
图片Coil 2.5
视频Media3 / ExoPlayer 1.2
文件访问SAF
语言Kotlin
构建Gradle + Kotlin DSL
